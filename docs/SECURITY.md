# Security notes
Synthetic data only. Host access and automatic content scripts are limited to `http://localhost/*` and `http://127.0.0.1/*`; the service worker separately rejects other hosts and Chrome internal pages. Page actions use an explicit tab message, a readiness probe, and controlled `scripting.executeScript` fallback. The content script excludes password, OTP, Aadhaar, PAN and payment credential field details from inspection. Page text is not sent to the backend. Notes receive a conservative keyword scrub but this is not a data-loss prevention guarantee. Simplify mode changes CSS and can have site-specific visual conflicts; restore removes UAL's injected styles, classes, tooltip, and view state. Field population is limited to the localhost synthetic demo portal, validates the property ID and ward, prompts before replacing conflicting values, and never submits the form. No real payment is initiated. Use only the demo portal.
