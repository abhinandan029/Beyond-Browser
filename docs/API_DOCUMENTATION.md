# API documentation
FastAPI interactive schema: `/docs` on local port 8000. Assistant input is `{message}`. The response includes intent key, display category, confidence, explanation, response, workflow and adapter. Tasks use UUIDs and store workflow checkpoint and page metadata. Fetch an individual latest checkpoint with `GET /api/tasks/{id}`. Notes are scrubbed for obvious sensitive terms. Verification accepts only a syntactically valid synthetic receipt reference and a boolean indicating that the demo marker was visible; raw page text is not sent. It returns `completed`, `awaiting_confirmation`, or `verification_failed`. Error responses use standard FastAPI HTTP errors.
