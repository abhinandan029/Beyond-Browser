# Architecture
The current runtime is a three-part system: React client, MV3 extension host/content script, and FastAPI service. The client invokes REST endpoints and Chrome runtime messages through a small UI boundary. The content script performs local page analysis and DOM guidance; only the API receives task intent and sanitized checkpoint metadata. SQLite is isolated behind small database functions and can be replaced with a repository implementation for PostgreSQL. Intent classification, workflow prediction, memory and verification are separate functions; the orchestration boundary can be replaced by LangGraph later. No specialist agent framework is falsely represented as implemented.
